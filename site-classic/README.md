# ГлобалМеталлХолд — классический сайт-визитка (статика)

Одностраничный B2B-сайт предприятия металлообработки на чистом HTML/CSS/JS —
без сборки, без Node.js и без интеграций. Готов к заливке на любой хостинг.

## Состав
- `index.html` — единственная страница (шапка → hero → о компании → услуги → оборудование → преимущества → портфолио → этапы → форма заявки → контакты+карта → футер)
- `style.css` — индустриальная тема: графит #1E1E1E/#2B2B2B + золото #FFD700/#D4AF37, анимации появления, адаптив от 320px
- `i18n.js` — словари RU/EN (переключатель в шапке, выбор запоминается в localStorage)
- `app.js` — рендер секций по словарю, валидация формы, drag&drop чертежа
- `favicon.svg` — иконка

## Заливка на хостинг
Скопируйте все файлы в корень сайта (public_html / htdocs). Ничего собирать не нужно.
Для локальной отладки: `python3 -m http.server 8000` → http://localhost:8000
(можно и открыть index.html двойным кликом — всё работает с file://).

## Форма заявки (без CRM)
Сервера нет, поэтому после валидации открывается почтовый клиент с готовым письмом
на sales@globalmetalhold.by (тема + данные из полей). Файл чертежа пользователь
прикрепляет вручную — браузер не может отправить файл в письмо без сервера.
Валидация на клиенте: имя/телефон/email обязательны; чертёж обязателен,
форматы .pdf/.dwg/.dxf/.zip/.rar, до 20 МБ.
